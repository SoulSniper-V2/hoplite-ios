# Hoplite for iOS

A quick little side project for using Hoplite on an iPhone. It talks to Hoplite's API. This is unofficial and isn't affiliated with, endorsed by, or supported by Hoplite.

## Run it

Requires Xcode 26.1 and [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```sh
brew install xcodegen
xcodegen generate
open Hoplite.xcodeproj
```

On first launch, sign in, use an API key, or explore the demo workspace.
